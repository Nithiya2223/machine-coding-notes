> **React + Node.js + Express + PostgreSQL**
> A complete, hands-on course that takes you from "I can write a React component" to "I can build and defend a full working product in a 90-minute interview."

---

## 📖 The Story Behind This Course

Imagine it's 10:58 AM. You join a video call. The interviewer shares their screen, pastes two sentences into a doc, and says:

> *"Build a group expense splitter. Users create groups, add expenses, and see who owes whom. You have 90 minutes. I'll run your app at the end."*

No multiple-choice. No "explain a closure." No whiteboard hand-waving. **They are going to click buttons in the app you build and watch it work — or watch it break.**

This is the **full stack machine coding round**, and it is the single highest-signal interview that product companies run. It tests everything at once: database design, REST API design, backend logic, React state management, error handling, and your ability to stay calm while building all of it under a clock.

This course is built around one promise: **you will never see an abstract `foo`/`bar` example.** Every problem is a real feature asked at a real company — Razorpay's payment flow, Swiggy's order tracking, Atlassian's Kanban board, Stripe's idempotency keys — and every solution is **100% complete, runnable code** across all three layers.

---

## 🎯 Who This Is For

- Engineers preparing for **product company** interviews (Razorpay, Swiggy, CRED, Atlassian, Stripe, Freshworks, Zoho, Postman, Notion, Zepto, Google, Meta).
- Anyone who can write *some* React or *some* Node but has never glued the full stack together under time pressure.
- People who keep "almost finishing" the problem and want a repeatable framework to finish *completely*.

**Prerequisites:** Basic JavaScript, basic React (`useState`, props), and willingness to type real code. Everything else — SQL, Express, JWT, WebSockets — is taught here from scratch with analogies.

## 🧱 The Stack (and why)

| Layer | Technology | Why this one |
|-------|-----------|--------------|
| Frontend | **React** (Vite) | The default UI library in every product-company round. |
| Backend | **Node.js + Express** | Fastest to scaffold a clean REST API in 90 minutes. |
| Database | **PostgreSQL** | Real relational modeling, JOINs, constraints, JSONB — what interviewers expect. |
| Auth | **JWT + bcrypt** | The standard for stateless auth in machine coding rounds. |
| Realtime | **Socket.io / SSE / polling** | Covered where the problem demands it. |

> Every concept ([JWT], [idempotency], [fan-out], [fractional indexing], etc.) is defined **in brackets on first use** so you are never lost.

## 🧭 How to Use This Course

1. **Do Module 00 first.** It is the foundation; everything else assumes it.
2. **Code along.** Do not just read. Type every file. The muscle memory is the point.
3. **Use the Time Budget** in each problem to simulate the real clock.
4. **Practice the Twists.** Interviewers *always* extend the base problem. The twists are where offers are won.
5. **Finish with the Mock Rounds** under a real timer, then score yourself with the checklist.

---

## 🎓 The Schema-First Mindset (the one idea that ties it all together)

> Your database schema is the foundation of your house. Build it wrong and everything above it is unstable. Get the schema right in the first 10 minutes and the rest flows naturally.

Every problem in this course starts at the database and works upward: **Schema → API contract → Backend skeleton → Fill backend → Build frontend.** Learn this rhythm once and you can attack *any* full stack problem.
